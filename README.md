# 三小时 · 最后一份牛肉汉堡

> 末日 · 校园 · 三小时
>
> “人类还有三小时。我想先吃个汉堡。”

一款**文字冒险游戏（视觉小说）**。全部画面、音效、剧情都由代码与剧本构成，
不依赖网络、不依赖任何图片或音频素材文件。

本项目根据《实验8 与AI的交互记录》中的游戏设定完整实现。

---

## 一、怎么玩

**直接双击 `index.html`**（放到网上后直接打开网址）即可开始，无需安装任何东西。
推荐用 Edge / Chrome 全屏（F11）游玩。

| 操作 | 说明 |
| --- | --- |
| 点击画面 / 空格 / 回车 | 推进对白（正在打字时：立即显示全文） |
| 数字键 1 ~ 4 | 选择选项 |
| Esc | 打开 / 关闭菜单 |
| 鼠标移动 | 画面轻微视差 |

存档是**自动**的，每推进一句都会保存，关掉网页也不会丢。
数据只存在你自己的浏览器里（localStorage），不上传任何地方。

## 二、故事

外星文明「雷德」的舰队逼近太阳系，距离全面降临地球只剩三小时。
人类社会秩序濒临崩塌。

你是**林默**，大四应届毕业生，佛系、轻度社恐、低欲望。
在这颗星球剩下的最后三小时里，你唯一想做的事是——
去食堂三楼，吃一个张阿姨做的、又干又硬的牛肉汉堡。

**主要角色**

- **林默**：主角。二十二岁，说话很少，想吃的东西很具体。
- **张桂兰**：食堂三楼汉堡窗口的守灯人。十年工龄，温柔，固执。
- **周野**：大三，反雷德自卫队发起人。信奉青年担当，执着抗争。
- **零号**：雷德文明先遣斥候，伪装成人类潜伏校园，编号 0412。
- **雷德**：那个要来清肃人类的文明。它不恨你，它只是写了一份报告。

## 三、系统

### 倒计时
从 **03:00:00** 开始。时间只在**你做出选择时**流动，
不同的选项会消耗不同的分钟数。走得越快，你能撞见的东西越多。

### 两个隐藏数值
- **执念**：你有多认真地对待自己想要的东西（那一个汉堡）。
- **牵挂**：你有多放不下别人（阿姨、同学、陌生人）。

它们不决定你能不能活下去，只决定你在最后一刻说得出什么话。

### 三个结局 · 六张卡
第三章的最后一次选择通向三条不同的路：

| 结局 | 路线 | 收场 |
| --- | --- | --- |
| 一 | 执念自守 | 你哪儿也没去，把汉堡认认真真吃完了 |
| 二 | 居间调停 | 你把半个汉堡递了出去 |
| 三 | 并肩抗争 | 你跟着十七个人冲了出去 |

同一条路，也会因为执念与牵挂的高低而有**残缺**与**完整**两种收场，
一共 6 张结局卡，收在「结局图鉴」里。

## 六、技术说明

- **纯前端**，四个 `<script>` 直接加载，无构建、无依赖、无网络请求。
- **画面**：每张场景是一个 `viewBox="0 0 1600 900"` 的 SVG，
  用渐变、剪影、径向光晕叠出层次，再配合 CSS 的慢速 ken-burns
  （44 秒推镜）与鼠标视差，让静态图有呼吸感。
- **声音**：`AudioContext` 现场合成低频铺底、噪声风、打字音、玻璃碎裂、
  上升音、合唱等，不加载任何音频文件。
- **存档**：`localStorage`（`sh_save` / `sh_settings` / `sh_gallery`）。
- **适配**：1600×900 的构图，按 `slice` 铺满任意 16:9 屏幕；
  窄屏会自动收缩字号与间距。

## 七、一点说明

游戏里没有“正确答案”。
执念自守不是自私，并肩抗争也不是勇敢，居间调停更不保证成功——
它们只是一个人在只剩三小时的时候，可能做出的三种选择。

祝你吃得下饭。

## 八、放到网上（GitHub Pages）

纯静态站点，根目录有 `index.html` 就能直接发布：

1. 新建一个 **Public** 仓库（名字随意），**不要**勾选自动生成 README。
2. 在本文件夹里打开终端：

   ```bash
   git init
   git add .
   git commit -m "三小时 · 最后一份牛肉汉堡"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 仓库 **Settings → Pages** → Deploy from a branch → `main` / `/ (root)` → Save。
4. 一两分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

注意：`css/`、`js/`、`预览图/` 这些文件夹要整块上传（保留层级），不要只拖里面的文件，否则样式和剧本都会 404。
